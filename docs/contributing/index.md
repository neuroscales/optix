# Contributing

optix is developed on [GitHub](https://github.com/neuroscales/optix). Bug
reports, new algorithms and improvements to the documentation are welcome.

- The [style guide](style.md) says how to write documentation and docstrings:
  citations, maths, notation and cross-references.
- New algorithm pages start from the
  [algorithm page template](../algorithms/_template.md) and use the common
  [notation](../concepts/notation.md).
