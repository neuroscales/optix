# Configuration

The options that decide where, in which precision and in how much memory a
computation runs. See [Estimators](../concepts/estimators.md#devices-dtypes-and-compilation)
for how they combine.

      heading_level: 2
      show_root_heading: true
      show_root_full_path: false
